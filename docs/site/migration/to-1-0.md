This page lists the changes known so far between Prism 0.x and 1.0. It grows as 1.0 nears, and the [Changelog](/docs/changelog) records each change in the release that makes it.

## How versions change

Before 1.0, a minor release may break you and a patch release never does. From 1.0, only a major release may break a Stable surface, and a Stable surface gets twelve months of notice before removal.

Anything with the `experimental_` prefix or an `--unstable-<feature>` flag can change in any release, including a patch. Pin the exact version if you use one.

## The command

| Before | From 1.0 | What to do |
| --- | --- | --- |
| `prismpm <verb>` | `prism <verb>` | Change your scripts when you can. `prismpm` stays as an alias through every 1.x release. |
| `prism-code check` with no holo | `prism-code build --check` | Change it now. The old spelling prints a warning and is removed in `prism-code` 0.4.0. |
| `prismpm check` validates the model | `prism check` judges a holo and prints a verdict | Use `prism-code build --check` to validate a model. Read the new exit codes: 0 pass, 1 fail, 2 no verdict. |
